Comment ça fonctionne

Ce tableau de bord fonctionne sans serveur via le localStorage de votre navigateur.

Étapes
  1. 1 Ouvrez index.html du site Velixio dans votre navigateur
  2. 2 Remplissez le formulaire de contact et choisissez un plan
  3. 3 Revenez ici — le message avec le plan choisi apparaît instantanément dans Messages

✅ Les messages sont synchronisés en temps réel via Firebase Firestore — accessibles depuis n'importe quel navigateur.
